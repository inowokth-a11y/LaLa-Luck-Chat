# KRUTH Element (Platform E)

**เริ่มที่นี่ก่อน:** อ่าน `CLAUDE.md` ให้ครบก่อนแตะโค้ดใดๆ — เป็นบันทึกการตัดสินใจ
ทั้งหมดจากเซสชันออกแบบร่วมกับผู้ใช้ (สูตรที่ verify แล้ว, สูตรที่ยังไม่ verify,
ธีมดีไซน์, และจุดที่ห้ามเปลี่ยนโดยไม่ถามก่อน)

## โครงสร้างโฟลเดอร์
- `CLAUDE.md` — บันทึกบริบท/สถาปัตยกรรม/สูตรทั้งหมด (**อ่านก่อนเสมอ**)
- `docs/KRUTH_21_Logic_Modules_v1.1.docx` — เอกสารสเปกทางการรวม (อ้างอิงหลัก)
- `docs/source-materials/` — เอกสารต้นทางทั้งหมด (ตำรา, Calculation Manual, System
  Prompt ตัวจริง, Chatbot Detection Logic Manual, เอกสารพัฒนาการที่ถูกรวมเข้า v1.1 แล้ว)
- `docs/design-assets/` — โลโก้ต้นฉบับความละเอียดสูง
- `legacy-python-engines/` — เอนจินคำนวณที่ทดสอบผ่านแล้ว (ต้นแบบสำหรับพอร์ตเป็น TS)
- `legacy-artifacts/` — หน้าตา UI ต้นแบบที่ทำงานได้จริงแล้ว (ต้นแบบสำหรับแปลงเป็น
  React components ใน `app/`)
- `data/*.json` — ฐานข้อมูลพร้อมใช้ (การ์ด 00-99, ฐานข้อมูลฝัน 457+50 รายการ)
- `data/raw-uploads/` — ตารางที่ยังไม่เคยเปิดใช้เนื้อหาเลยตลอดเซสชันนี้ (ต้องตรวจสอบ
  ก่อน merge เข้าระบบ เพราะบางไฟล์อาจซ้อนทับกับสิ่งที่สร้างขึ้นเองแล้ว)
- `data/sensitive/` — ⚠️ ข้อมูลผู้ใช้จริง มี `.gitignore` กันไว้ อ่าน README ในนั้นก่อนแตะ
- `supabase/migrations/` — SQL ที่ต้องรันตามลำดับเลขไฟล์ (ยังไม่เคยรันจริง)
- `app/`, `lib/` — โครง Next.js เปล่า รอ Claude Code เติม
